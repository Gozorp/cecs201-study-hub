# CECS 201 Study Hub

**Live site:** https://gozorp.github.io/cecs201-study-hub/

A study companion for CSULB **CECS 201 — Computer Logic Design I**. Browse 102 lecture and lab videos by topic, with auto-generated transcripts and a clickable timeline that jumps the video to any caption line.

> *Shared publicly with instructor permission to help current and future students study.*

## How it works

- The HTML/CSS/JS site and the `.vtt` transcript files are served via GitHub Pages from this repo.
- The `.mp4` lecture videos are stored as assets on the [v1.0 release](https://github.com/Gozorp/cecs201-study-hub/releases/tag/v1.0) (2.85 GB total). The site streams them directly from there.

## Modules

- **Topics 1–7**: Number Systems, Boolean Algebra, Combinational Logic, Sequential Logic, Memory & State Machines, etc.
- **Labs 1–8**: Vivado intro, testbench creation, FPGA implementation, FSM design.
- **Final Exam**: Topic deep-dives.
